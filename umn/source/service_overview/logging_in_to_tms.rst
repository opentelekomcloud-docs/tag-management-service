Logging In to TMS
=================

You can access TMS from the management console, or call application programming interfaces (APIs) to use the service.

-  APIs

   To integrate TMS into a third-party system for secondary development, use TMS APIs. For details, see `Tag Management Service API Reference <https://docs.otc.t-systems.com/tag-management-service/api-ref/>`__.

-  Management console

   The management console is a web-based UI where you can easily perform various operations. You can log in to the management console, click |image1|, and choose **Tag Management Service** under **Management & Deployment**.
